Built production multi-agent AI framework design to be domain-agnostic and reusable across any LLM use case. Core is a ReACT orchestration engine that coordinates specialized sub-agents as tools, routing work through delegation chains where each hop is scoped to minimum permissions and signed with HMAC-SHA256. ToolGateway enforces those scopes at every tool call, blocking confused deputy attacks at the framework level before they reach the model.

Framework ships with Delta-backed shared memory across endpoints: short-term session state, long-term user history, and a knowledge graph, all consistent regardless of which endpoint handles the request. A configurable HITL engine scores confidence as a composite of LLM self-assessment, source coverage, tool result consistency, category risk, and error history, escalating to a human reviewer only when the score falls below a threshold. Everything else runs autonomously.

Plugin hooks at pre-LLM and post-tool boundaries give any downstream use case auditing, rate limiting, budget enforcement, and security enforcement without touching agent logic. MLflow traces every decision end-to-end. Feedback routes back to MLflow Assessments via custom actions functions, closing the evaluation loop. Framework is now the standard agentic platform across the organization with thirty plus use cases building on top of it.
