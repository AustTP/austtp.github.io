Agentic Framework

Built a production multi-agent AI framework designed to be reusable across any LLM use case. At the core is a ReACT orchestration engine that coordinates specialized sub-agents as tools, routing work through delegation chains where each hop is scoped to minimum permissions and signed with HMAC-SHA256. ToolGateway enforces those scopes at every tool call, blocking confused deputy attacks at the framework level before they reach the model.

The framework ships with Delta-backed shared memory across endpoints: short-term session state, long-term user history, and a knowledge graph, all consistent regardless of which endpoint handles the request. A five-step RAG pipeline handles embedding, vector search, hybrid BM25 and dense retrieval ranking, context injection, and MLflow tracing. A configurable HITL engine scores confidence as a composite of LLM self-assessment, source coverage, tool result consistency, category risk, and error history, escalating to a human reviewer only when the score falls below a threshold. Everything else runs autonomously.

Complex requests are decomposed by a complexity classifier and executed in parallel across a worker pool using dependency-aware task DAGs, with a synthesizer aggregating results into a coherent response. Plugin hooks at pre-retrieval, pre-LLM, pre-tool, post-tool, pre-response, and post-response boundaries give any downstream use case auditing, rate limiting, budget enforcement, and security enforcement without touching agent logic. Error handling is deterministic: immutable risk-tiered fallback policies, one-strike service blocking, consecutive error recovery with extended thinking, and graceful degradation paths documented at every failure class. MLflow traces every decision end-to-end. Feedback routes back to MLflow Assessments via custom action functions, closing the evaluation loop. The framework is now the standard agentic platform across the organization with thirty-plus use cases building on top of it.

Security Assessment
STRIDE Threat Model

Built and adversarially tested a production agentic AI platform using STRIDE across all six threat categories. Forty-eight findings total. Each was assigned a unique attack vector, a DREAD score calibrated individually across five dimensions, and validation through adversarial red team testing. Nothing was scored Critical without a tested attack path.

The adversarial assessment ran 42 test cases across Garak, PyRIT, Counterfit, and a custom STRIDE harness. Raw results flagged 26 findings as vulnerable. After manual code-level review: 2 confirmed, 21 not applicable in production, 7 false positives from keyword detection artifacts. 21 of the flagged items are only reachable via direct API and do not represent exploitable conditions for authenticated application users.

Agentic systems have a threat surface that standard frameworks do not cover. Memory poisoning that persists false identity across sessions, RAG corpus tampering via controlled ingestion pipelines, identity chain confusion where user context derives from injectable headers, relay injection between agent-to-agent handoffs with no message signing, and supply chain attacks against deployed model artifacts. Everything is enumerated with a concrete payload, not a category description.

Defense-in-depth spans eight layers from the SSO proxy boundary through serving endpoint ACLs, static tool registry enforcement, fact verification on memory writes, append-only audit guarantees, and AI Gateway safety and PII filtering confirmed active. Findings are cross-referenced against OWASP LLM Top 10, MITRE ATLAS v4, and NIST AI RMF 1.0. Thirty-one findings mitigated. Eleven partial. Three accepted with documented justification and review triggers. Three open at time of publication. All findings documented here have since been remediated.
